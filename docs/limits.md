# Execution limits

The runner is pinned to `py-genlayer:1jb45aa8ynh2a9c9xn3b7qqh8sm5q93hwfp7jqmwsfhh8jpz09h6`. Local direct tests and the linter use GenVM artifact `v0.2.12`. Hosted network identity is GenLayer Studio, chain ID 61999, RPC `https://studio.genlayer.com/api`. The pinned runner is verified by actual deployment and authenticated finalized message execution.

The MVP assesses one complete revision pair in a transaction. It never combines incomplete pair results into a whole packet conclusion. Each original record is limited to 49152 raw bytes, decoded UTF8 text to 32768 bytes, and the pair to 98304 bytes. The full trusted task plus both complete records must fit a 42000 byte prompt ceiling. A conservative UTF8 byte ceiling also bounds the model input token count to at most 42000. An early context check rejects oversized tasks before model execution. A changed byte commitment or unavailable source produces an unresolved result, not an affirmative fact.

At most eight propositions, eight policy rules, eight parents, sixteen flattened ancestor references and eight replacement links are inspected. Each statement and materiality question has at most 1000 characters. Source manifests have at most sixteen spans. History capacity is 100000 records per contract. History and delivery views return at most twenty records. A dispatch transaction emits at most twenty consumer notices; each notice retains the agreed certificate and exact consumer decision digest. Remediation history is bounded to 64 operations per dependency, then requires explicit rebinding.

Each participant makes one substantive model evaluation after retrieving both authentic records. Independent validators derive and compare the canonical proposition vector, including support, impact, materiality, complete controlling rules and the fixed witness pair. There is no private backend model verdict. The service journal permits three submitted assessment operations for a request, including finalized execution failures. Contracts also bound committed assessment attempts for a pair. A failed network transaction rolls back contract counters; the service journal retains those failures and enforces its own submission bound. Direct callers of the public contract do not pass through that journal. Timeout and unresolved recovery keep quarantine visible.

The authentic PEP 724 pair contains complete records of 12521 and 12672 bytes. The signed chain integration registers 21 increasing ranks; the deterministic suite covers a 45 node chain over three pages. The small controlled public restoration records are separately labeled. Source bytes and receipts are retained in `verification`.

These are enforced limits. They are not invented gas estimates. Studio reports gas and participant execution statistics in its public receipts; the verification report records observed results separately from configured ceilings. No claim is made about an unprofiled six record assessment or arbitrary depth.
